## Bemærk om placering

Markederne og varerne i appen er eksempeldata fra Slagelse. Kortet viser kun varer inden for 1, 3 eller 10 km fra din placering. Hvis du ikke befinder dig i Slagelse, så tryk **Tillad ikke**, når appen spørger om din placering. Så bruger appen automatisk Slagelse centrum, og du kan se markederne og varerne på kortet.
